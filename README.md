# Milo — Single-Player Edition

This is the GitHub Pages-ready version of Milo. Multiplayer, room creation,
room joining, room codes, and in-game chat have been removed.

## Files
- `index.html` — the complete single-player game.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` directly into the repository's top level (not inside
   another folder).
3. Commit the change.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose your main branch and the `/(root)` folder, then save.
7. When GitHub Pages finishes publishing, open the website URL it provides.
8. Update the PLAY link on your Google Sites homepage to that URL.

No `server.js`, `package.json`, `render.yaml`, Node.js, or multiplayer hosting
is needed for this single-player version.

The game loads Tailwind CSS and Font Awesome from their public CDNs, so players
need an internet connection when opening the game.
