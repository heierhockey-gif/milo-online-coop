MILO THE ELECTRICIAN — ONLINE THREE-PLAYER CO-OP

WHAT CHANGED
- The existing game, levels, graphics, characters, controls, powers, lives and chat are retained.
- Private rooms use a six-character code you can share with friends.
- Public rooms appear in the lobby so players can join as Ludwig or Plum.
- Multiplayer now uses one secure-compatible WebSocket endpoint, so it can run over HTTPS/WSS on a cloud host.
- Up to three players: Milo (host), Ludwig (player 2), and Plum (player 3).

PLAY WITH PEOPLE ANYWHERE (CLOUD DEPLOYMENT REQUIRED ONCE)
1. Create a free account at https://render.com/ and a GitHub account at https://github.com/ if you do not already have them.
2. Create a new GitHub repository and upload the contents of this folder (all files, not the ZIP itself).
3. In Render, choose New > Blueprint, connect that repository, and let Render read render.yaml.
4. Deploy the web service. Render will provide a public https:// address.
5. Open that same address on each player's device. The host chooses CREATE PRIVATE or CREATE PUBLIC.
6. For a private game, share the six-character room code. Friends enter it and choose JOIN AS LUDWIG or JOIN AS PLUM.
7. For a public game, friends choose the room from PUBLIC ROOMS and select an open player slot.

IMPORTANT: The ZIP is deployment-ready, but it is not already hosted on the internet. A cloud service must be deployed once to create the public game address. The public room list is held in server memory and will reset if the service restarts or sleeps; active rooms are not persistent.

LOCAL TESTING (SAME WI-FI)
1. Extract the ZIP into a folder and keep all files together.
2. Install Python 3 if needed.
3. Double-click START_MILO_COOP.bat and leave its window open.
4. Open the local network address printed in the window on the host and other devices.
5. Host creates a room; players join using the code.

During a level, the lobby hides automatically and returns on the home map. The host computer must stay connected while the room is active. Closing the server or host ends the room.
